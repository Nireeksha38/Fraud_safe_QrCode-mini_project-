QR Payment Verification System

Status: Work in Progress 🚧

This project aims to improve QR payment safety by extracting QR details and reading the recipient information before payment confirmation.

Technologies Used:
- React Native
- Expo
- JavaScript

Current Features:
- QR code scanning
- Extracting QR information
- Displaying recipient details

Future Improvements:
- UPI verification
- Fraud detection rules
- Voice alerts
- Better user interface
